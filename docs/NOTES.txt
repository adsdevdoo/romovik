2026-11-22 — начало ROMовика
- Владелец создал публичный adsdevdoo/romovik; основной адрес rom.creepypaste.rs, DNS создан в этом чате.
- По решению владельца: никакой админки/БД; дампы, модель, фото и описание передаются помощнику. Статический Astro + Tailwind; отдельные HTML карточки, sitemap/robots/canonical, поиск без сервера.
- Маркировка и производитель берутся с фото. Первый исходный файл содержит опечатку NMG вместо NMC. Неподтверждённые коды не расшифровывать. Происхождение всех первых трёх ПЗУ неизвестно; проверка чтения не сообщена, в устройстве не проверены.
- NMC27C256Q-25 (National Semiconductor), AM27C256-205DC (AMD), M27C256B-12F1 (STMicroelectronics): по 32768 байт, три разных SHA-256. Исходники и фото отдельно от Git; хеши и размеры в карточках, сборка сверяет их.
- По просьбе владельца извлекать строки для поиска. В NMC найдены IMATIC 95, Copyright (c) 95 by IMATIC (r), IMATIC Yugoslavia, POKER BONUS; связь с видеопокером — предположение. В ST — SUPERCLUB 750 RUSSIA, названия тестов. В AMD содержательных ASCII-строк не обнаружено; графика и другие кодировки не исключаются.
- В HTML входят только отобранные строки с точными смещениями; перед сборкой сверяются с байтами. Повторы и случайный бинарный текст не публикуются автоматически.
- Локальная Node 22.23.4 установлена зависимостью проекта, системная Node не менялась. В PowerShell npm.ps1 поглощает именованные CLI-параметры: использовать npm.cmd либо node scripts/add-dump.mjs.
- Предпросмотр: проверены поиск National, фильтр без результатов, сброс, карточка, копирование SHA-256, загрузка фото, мобильная ширина 390 без горизонтального переполнения. Ошибок консоли не было.
- Перед первой публикацией: npm test 8/8; build и check:dist — 6 HTML-страниц, 91 внутренняя ссылка, 3 дампа и фотографии, строки в HTML, sitemap/robots, JSON-LD. Конфигурация размещения прошла независимый аудит без блокирующих замечаний.

Владелец уточняет фактический/ожидаемый ID через верхнюю кнопку ID CHECK. Источник: https://media.digikey.com/pdf/Data%20Sheets/AMD/Am27C256.pdf.
